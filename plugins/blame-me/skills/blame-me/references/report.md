# Report templates

Use the template in the language of the work. Replace everything in angle brackets. Keep the order. Use plain words: if a reader needs a dictionary, rewrite it.

## English

```
Panel: <seat 1>, <seat 2>, <seat 3>. Each read <separately, as separate helpers that did not see each other | in turn, all played by one model>. They saw <the work> <and the brief / criteria>, nothing else.

Verdicts
- <Seat 1>: <Pass | Fail>. <one or two sentences>
- <Seat 2>: <Pass | Fail>. <...>
- <Seat 3>: <Pass | Fail>. <...>
<Scores, only if criteria were given, using the user's criteria and scale.>

Weak spots
1. [<Must fix first | Should fix | Good to fix> · <n>/<panel size>] <short title in plain words>
   Where in the work: "<short quote>" (<section>) <+ "<quote>" (<section>)>
   When it goes wrong: <the real moment it causes trouble>
   Quick way to check: <something this user can do this week, with little or no money>
2. ...

Already holds up
- <what> — <what the panel tried, and why it held>
<or: Nothing held up when the panel tried to break it.>

Needs checking
- <what> — check <how, where>.

Start here: <the one weak spot to deal with first> — <its quick check>.

Want help fixing any of these?
```

## ภาษาไทย

```
กรรมการ: <ที่นั่ง 1>, <ที่นั่ง 2>, <ที่นั่ง 3> แต่ละคน<อ่านแยกกัน ไม่เห็นความเห็นของกัน | อ่านทีละบทบาท โดยโมเดลเดียวสลับเล่น> เห็นแค่<ตัวงาน> <และโจทย์/เกณฑ์> ไม่เห็นอย่างอื่น

คำตัดสิน
- <ที่นั่ง 1>: <ผ่าน | ไม่ผ่าน> <เหตุผลหนึ่งถึงสองประโยค>
- <ที่นั่ง 2>: <ผ่าน | ไม่ผ่าน> <...>
- <ที่นั่ง 3>: <ผ่าน | ไม่ผ่าน> <...>
<คะแนน ใส่เฉพาะเมื่อมีเกณฑ์ ใช้หัวข้อและสเกลตามเกณฑ์นั้น>

จุดอ่อน
1. [<ต้องแก้ก่อนไปต่อ | ควรแก้ | แก้ก็ดี> · <n>/<จำนวนกรรมการ>] <หัวข้อสั้นๆ คำง่ายๆ>
   ตรงไหนในงาน: "<ข้อความสั้นๆ ที่ยกมา>" (<หัวข้อ>) <+ "<ข้อความ>" (<หัวข้อ>)>
   จะเป็นปัญหาตอนไหน: <ตอนไหนที่มันจะเกิดเรื่องจริง>
   ลองเช็กง่ายๆ: <สิ่งที่คนนี้ทำได้ภายในสัปดาห์ แทบไม่ต้องใช้เงิน>
2. ...

ส่วนที่ใช้ได้แล้ว
- <อะไร> — <กรรมการลองหาจุดอ่อนอะไร แล้วทำไมมันยังยืนอยู่>
<หรือ: ไม่มีส่วนไหนที่ยังยืนอยู่หลังกรรมการลองหาจุดอ่อน>

ต้องเช็กเพิ่ม
- <อะไร> — เช็ก<ยังไง ที่ไหน>

เริ่มจากตรงนี้: <จุดอ่อนข้อเดียวที่ควรจัดการก่อน> — <วิธีเช็กของข้อนั้น>

จะให้ช่วยแก้ข้อไหนไหม
```

## Levels, in one line each

| English | ไทย | Meaning |
|---|---|---|
| Must fix first | ต้องแก้ก่อนไปต่อ | If true, the whole work fails. Every sale loses money; the brief asks for X and X is not there. |
| Should fix | ควรแก้ | The reader will say no, or stop believing the work, unless this is fixed. |
| Good to fix | แก้ก็ดี | It weakens the work or makes it look careless, but does not sink it. |

## Good and bad wording

| Instead of | Write |
|---|---|
| unit economics are negative | each sale loses money |
| CAC is not stated | the work does not say what it costs to win one customer |
| no evidence of product-market fit | nothing shows that people want this enough to pay |
| runway | how many months the money lasts |
| stakeholder misalignment | the people who must agree are not the people the work talks to |
| ต้นทุนต่อหน่วยติดลบ | ขายได้หนึ่งชิ้นก็ขาดทุนหนึ่งชิ้น |
| ไม่มี value proposition ที่ชัดเจน | งานไม่ได้บอกว่าทำไมคนต้องเลือกอันนี้แทนสิ่งที่ใช้อยู่ |
