# Re-read after fixes

Use when the user brings a new version of the work together with an earlier blame-me report.

## Steps

1. **Status of every earlier weak spot.** Compare each one with the new version and mark:
   - **Fixed** (แก้แล้ว): the problem is gone. Quote the new text that removes it.
   - **Partly fixed** (แก้บางส่วน): better, but not gone. Say what is still missing.
   - **Not fixed** (ยังไม่ได้แก้): unchanged, or changed without removing the problem.
2. **A fresh first read.** Run the same panel on the new version as if for the first time. They see only the new version and the brief, not the earlier report or the status list. A fix often looks fine to someone who knows what it was meant to fix, and wrong to someone who does not.
3. **Look for problems the fixes caused.** Check especially:
   - a number changed in one place but not in the places that depend on it;
   - a new or rewritten part that disagrees with a part that was not touched;
   - a mention of a page, picture, or appendix that was removed or renumbered;
   - a fix that answers the old weak spot but raises a new question.
4. **Report.**

## Template (English)

```

Earlier weak spots
1. <title> — <Fixed | Partly fixed | Not fixed>. <quote from the new version>
2. ...

New weak spots
1. [<Must fix first | Should fix | Good to fix> · <n>/<panel size>] <title>
   Where in the work: ...
   When it goes wrong: ...
   Quick way to check: ...

Already holds up
- ...

Needs checking
- ...

Start here: ...

Want help fixing any of these?
```
